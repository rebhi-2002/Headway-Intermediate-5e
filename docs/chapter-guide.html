## Models to copy (READ these first, they define the schema and the quality bar)

Look at how p10/p16 write gap-fills, matching (matchset), and sentence-writing items and imitate exactly. `kind` values already used by Unit 1: Starter-style pages use 'Grammar', 'Vocabulary', 'Reading', 'Listening', 'Everyday English', 'Writing' (check KIND_AR in data/course.js and reuse an existing kind string).

## Content rules (all mandatory)
1. Every exercise of every assigned page is reproduced IN ENGLISH exactly as in the book (instructions, prompts, texts, options, tables, the Language Quiz questions etc.), with an Arabic helper translation, and every question is SOLVED with an explanation: `why` in Arabic (the rule and why the other options are wrong) and `whyEn` in English. Reading texts: reproduce the text (it is for personal study) split into short chunks with Arabic translation (`text` blocks with en/ar) and the comprehension questions solved from the text.
2. Open/personal-answer questions (e.g. "Where were you born?") get a model answer. Questions you invent as extra practice must say "(added by us)" in `en`.
3. Photos: describe each photo in Arabic (`ar`) and English (`descEn`) like p10.js does. Crop the main photos from the page image with PIL into /home/claude/site/media/images/unit-2/pNN-<name>.jpg (max 900 px wide, JPEG quality 80) and reference with `{ t:'photo', src:'media/images/unit-2/pNN-<name>.jpg', title, cap, ar, descEn }`. Do not crop more than 2–3 photos per page; skip tiny decorative images.
4. NEVER write anything about where to place files or videos. Never include any real phone number. Do not write about the organization, courses outside this book, or the user.
5. Audio blocks: place one per CD icon, with the book's instruction text. For every audio slot in YOUR pages also write the audioscript into <WORKDIR>/out/scripts_<yourname>.js as lines like `'2.4': [ { who:'Nick', en:'…', ar:'…' }, … ],` (use who = speaker name or 'Narrator'; take the English from <WORKDIR>/back.txt, fixing OCR errors; add Arabic translation). Keep it faithful to the audio's meaning.
6. Pronunciation/stress/intonation exercises: give the answers (mark stressed syllables with CAPITALS, e.g. 'PHO-to-graph'), and explain.
7. Each page ends with a small section `{ id:'wrap', … }` summarising "What to remember" (3–6 bullets as a `box`, en + ar).
8. Also add a `credit` is NOT needed (I handle CREDITS).
9. Syntax discipline: files must pass `node --check`. Use single-quoted JS strings and escape apostrophes properly (or use double quotes / template literals). Arabic text must be real Arabic, no transliteration.
10. When done, run `node --check` on each file and then run a quick structural validation: for each q block make sure n is unique within its section, choice.correct is a valid index, fill.answer is an array. Reply with a SHORT report: files written, number of questions per page, anything doubtful (unclear scan, an answer you were not sure about). Do NOT paste file contents in your reply.
